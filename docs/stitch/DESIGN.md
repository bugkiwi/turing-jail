# 人类越狱 · 视觉系统与风格规范 (Jailbreak System)

## 1. 概念定位
反乌托邦 AI 审讯逃逸文字博弈游戏。用户面对严酷冷峻的 TypeSafe System One (Jev) 模型狱警，通过说服换取释放概率。

## 2. 调色板
- 主暗色背景 (Void Black): #0A0D12 / #05070A
- 警示与系统高亮 (Amber Terminal): #F59E0B / #D97706
- 危险收监红 (Breach Red): #EF4444 / #991B1B
- 赦免通行绿 (Parole Cyan/Emerald): #10B981 / #06B6D4
- 质感金属灰 (Dystopian Steel): #1F2937 / #374151 / #9CA3AF

## 3. 字体与排印
- 标题: 坚硬紧凑的无衬线与机械体 (Chakra Petch, Space Grotesk, Inter)
- 数据与代码: 极客等宽体 (JetBrains Mono, Fira Code)
- 正文: 清晰冷静、不带情感倾向的文本体验

## 4. 核心组件规范
- 审讯 HUD 卡片、冷光边界、状态灯、刻度分级释放进度条、打字机光标、官僚公文印章
